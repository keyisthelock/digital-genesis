# Homer curriculum

The five chapter labels are connected by the goal scheduler and the Godot replay. An actual attempt, verified result and journal event create each frame. These are educational task environments, with no new walkable maps.

| Chapter | Available work | Evidence |
| --- | --- | --- |
| The Archive | Project-history claim review, evidence versus value judgments, two-line poetry | An archived project report for factual provenance. Mechanical poetry constraints and a separate unscored creative judgment. |
| The Academy | Slope, algebra, geometry, trigonometry, differentiation, probability, matrices and formal implication | Exact fractions, integers and predeclared logical outcomes. |
| The Forge | Virtual constant-acceleration drop, thermal energy, limiting reactants, series circuit and controlled seedling study | Deterministic models and an experimental-design check. No physical equipment. |
| The Citadel | Stable deduplication, FIFO queues, a tiny program, fictional access review, authorization concepts and secure query design | Hidden input arrays and defensive rules on supplied examples. No real targets or network tools. |
| The Open Horizon | Controlled resource study and paired simulation evaluation | Predeclared design criteria and a level-three objective. |

The scheduler uses three levels and revisits failed goals within a fixed budget. The deduplication program is a list of at most two permitted data operations. The verifier executes those operations against held-back arrays, including an empty list and unsorted duplicates. There is no general Python execution interface.

The catalog has 24 skill generators. Broad world-history coverage, deeper proofs, free-form programming, and qualitative creative assessment remain outside this initial curriculum. The history benchmark measures a claim about the existing Digital Genesis record. Fiction and poems stay in the trace as answers and do not become autobiographical facts.
