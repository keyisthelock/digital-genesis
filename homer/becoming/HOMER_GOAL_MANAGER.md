# Homer goal manager

An operator chooses the permitted curriculum and attempt budget before an episode. The manager compares public skill labels and levels, novelty, a competence gap based on recalled feedback, practice preference, and cost. Novelty decreases with attempts. A remembered failure increases practice value. A task with positive risk or excessive cost is ineligible. After two tries at one skill, that candidate is retired for the episode. The trace records candidate scores, selected goal, active signals and retired skills.

The matched slope test presents the same two generated problems in both arms. The memory-enabled policy retrieves a verified failed attempt and switches from its shortcut to the worked method. The disabled arm records results but supplies no previous feedback to the scheduler or method policy. The scheduler has no access to test answers.

A documented preference proposal raised the reflection setting from 0.70 to 0.72 after one verified failure. It wrote a separate profile and a linked revision event. A supplied revision is accepted only if identity, heritage pointer and core values match the canonical profile and every adjustable value is in range. This shows an update rule. There is no measured personality benefit from that change.
